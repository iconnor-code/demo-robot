## 通用约定

- 平移单位 m；题面角度 deg，代码内一律 rad；
- 姿态为**固定角 ZYX（RPY）**：`R = Rz(rz) @ Ry(ry) @ Rx(rx)`，记 `(rx, ry, rz)`；
- 四元数 Hamilton 约定，顺序 `(x, y, z, w)`，`R(q1 ⊗ q2) = R(q1) @ R(q2)`；
- `T_AB` 表示 B 系在 A 系下的位姿（`p_A = T_AB @ p_B`）；链式法则 `T_AC = T_AB @ T_BC`；
  求逆 `T_BA = T_AB⁻¹ = [Rᵀ, −Rᵀt; 0 1]`（利用旋转矩阵正交性，无需通用矩阵求逆）；
- "刚性夹持"：夹紧后工件与夹爪无相对运动，`T_tcp_part` 为常量。

## B.1 反解：已知工件位姿 → 求法兰位姿

**模型**（本小题工件系与夹持中心重合，`T_part_tcp = I`）：

```
T_base_part = T_base_flange @ T_flange_tcp
=>  T_base_flange = T_base_part @ T_flange_tcp⁻¹
```

已知：`T_flange_tcp`：平移 (0, 0, 0.165)，RPY (0, 0, 45)；
`T_base_part`：平移 (0.520, −0.180, 0.120)，RPY (180, 0, −30)。

**结果**（`solve_b1.py` 输出）：

| 量 | 值 |
| --- | --- |
| 平移 | **(0.520000, −0.180000, 0.285000) m** |
| RPY | **(180°, 0°, 15°)** |
| 四元数 (x, y, z, w) | **(0.991445, 0.130526, 0.000000, 0.000000)** |

旋转矩阵：

```
[  0.965926   0.258819   0.000000 ]
[  0.258819  -0.965926   0.000000 ]
[  0.000000   0.000000  -1.000000 ]
```

封闭解核对：`R_bf = Rz(−30°)Rx(180°)Rz(−45°) = Rz(15°)Rx(180°)`（利用
`Rx(180°)Rz(α) = Rz(−α)Rx(180°)`），`t_bf = t_bp − R_bf·(0,0,0.165) = (0.520, −0.180, 0.285)`，
与数值解一致。

**两种独立方式交叉验证**（要求差 < 1e−9）：

- **路径 A（旋转矩阵）**：全程 4×4 齐次矩阵，用自实现的 `T_mul` / `T_inv`；
- **路径 B（四元数）**：姿态用轴角四元数经 `⊗`、共轭组合（`q_bf = q_bp ⊗ q_ft*`），
  平移用三明治积旋转矢量（`t_bf = t_bp − q_bf ⊗ (0,t_ft) ⊗ q_bf*`），RPY 直接由四元数
  分量公式解出，全程不构造任何矩阵。

实测差异：`|Δt| = 0`、`|Δq| = 1.1e−16`、`|ΔRPY| = 3.6e−15°`，远小于 1e−9 ✔。

## B.2 正解 + 下料反解

**安装链**：`T_base_part = T_base_flange @ T_flange_tcp @ T_tcp_part`

已知：`T_base_flange` (0.420, 0.150, 0.560) RPY (150, 0, 45)；
`T_flange_tcp` (0, 0, 0.165) RPY (0, 0, 90)；`T_tcp_part` (0.025, 0, 0.060) RPY (0, 0, 0)。

### 1. 正解结果

| 位姿 | 平移 / m | RPY / deg | 四元数 (x, y, z, w) |
| --- | --- | --- | --- |
| `T_base_tcp`（TCP 位姿） | **(0.478336, 0.091664, 0.417106)** | **(180, −30, −45)** | (0.892399, −0.369644, 0.239118, 0.099046) |
| `T_base_part`（工件位姿） | **(0.514859, 0.055141, 0.377644)** | **(180, −30, −45)** | 同上（偏心无旋转） |

### 2. 反向校验与常量链合并（TCP 标定）

反向校验：`T_base_part @ T_flange_part⁻¹` 与给定 `T_base_flange` 最大元素差 = **0.0**（< 1e−9）✔。

常量链合并结果：

```
T_flange_part = T_flange_tcp @ T_tcp_part
              = 平移 (0.000000, 0.025000, 0.225000)，RPY (0, 0, 90)
```

**这样做的好处**：

1. **省实时计算**：`T_flange_tcp @ T_tcp_part` 只在装夹/标定时算一次并缓存，运行时每个
   周期少一次 4×4 矩阵乘法（正解/反解都只剩一次乘法），也减少浮点误差累积；
2. **标定即一个对象**：这就是机器人控制器里"工具坐标系（TOOL/TCP）设置"——标定的是
   "法兰 → 工件"这一个整体变换，换夹爪/改夹持偏心只需重标这一个量，业务代码不变；
3. **语义清晰**：视觉给的工件位姿可直接 `T_flange_target = T_base_part @ T_flange_part⁻¹`
   一步反解到法兰，安装细节被封装在标定值里。

### 3. 下料放置

目标：`T_base_part_target` 平移 (0.350, −0.450, 0.090)，RPY (180, 0, 0)（工件水平放、
+Z 朝下）。

法兰目标位姿 = `T_base_part_target @ T_flange_part⁻¹`：

| 量 | 值 |
| --- | --- |
| 平移 | **(0.325000, −0.450000, 0.315000) m** |
| RPY | **(180°, 0°, 90°)** |
| 四元数 (x, y, z, w) | (0.707107, 0.707107, 0.000000, 0.000000) |

回代验证：`T_base_flange_target @ T_flange_part` 与目标位姿最大元素差 = **0.0**（< 1e−9），
工件精确落在料盘目标位姿 ✔。直观性也对：工具竖直朝下，法兰 z 比工件 z 高 0.225 m
（常量链沿法兰 Z 的伸出量）。

## B.3 eye-to-hand 视觉引导定位

已知：内参 fx = fy = 800.0 px、cx = 640.0、cy = 360.0 px（1280×720，忽略畸变）；
手眼外参 `T_base_cam` 平移 (0.700, −0.200, 1.000) RPY (180, 0, 15)（相机吊装俯视）；
视觉输出圆盘中心像素 (720, 280)、深度 0.400 m；夹爪同 B.1。

### 1. 像素 → 相机系（针孔模型反投影）

```
x_c = (u − cx)/fx · z_c = (720−640)/800 × 0.4 = +0.040 m
y_c = (v − cy)/fy · z_c = (280−360)/800 × 0.4 = −0.040 m
z_c = 0.400 m        =>  P_cam = (0.040, −0.040, 0.400)
```

### 2. 相机系 → 基座系

`P_base = T_base_cam @ P_cam =` **(0.728284, −0.151010, 0.600) m**
（相机高 1.0 m、物深 0.4 m，圆心落在台面 z = 0.6 m，数值自洽）。

**为什么这一步用不到机器人当前位姿？** 这是 eye-to-hand（眼在手外）结构：相机与基座
之间的外参 `T_base_cam` 由手眼标定一次性确定，装好后**固定不变**，是工作站的一个静态
几何参数；像素 → 基座系的换算只依赖这条固定的安装关系，与机器人此刻在哪里、法兰在
什么姿态毫无关系。（对比 eye-in-hand：相机随法兰运动，每次拍照都要用**当时的法兰
位姿**参与链式变换——那才会用到机器人位姿。）

### 3. 工件完整位姿（6 DoF）

圆盘平放、法向竖直，取 `T_base_disc`：平移 = 圆心 (0.728284, −0.151010, 0.600)，
姿态 RPY (180, 0, 0)（rz 任意，抓取无约束）。

**为什么圆盘不需要"长轴角度"？** 圆盘绕自身法向（竖直轴）**旋转对称**：夹爪绕基座 Z
转到任何方位角去夹，圆盘与夹爪的相对几何完全相同，都能对中夹紧，所以绕 Z 的朝向是
冗余自由度，视觉不必给出角度，规划时可任取（本解取 0）。长条工件则不同：其外形
只在长轴方向上"对中"，夹爪必须与长轴对齐，绕 Z 的角度是硬约束，视觉必须测出这条
长轴在图像里的角度。

### 4. 法兰目标位姿（套 B.1 公式）+ 回代验证

```
T_base_flange_target = T_base_disc @ T_flange_tcp⁻¹
```

| 量 | 值 |
| --- | --- |
| 平移 | **(0.728284, −0.151010, 0.765000) m** |
| RPY | **(180°, 0°, 45°)** |
| 四元数 (x, y, z, w) | (0.923880, 0.382683, 0.000000, 0.000000) |

回代验证：`T_base_flange_target @ T_flange_tcp` 的夹持中心 = (0.728284, −0.151010,
0.600) m，与圆盘中心最大差 0.0 m（< 1e−9）；姿态差 1.0e−17。夹持中心精确落在圆盘
中心上 ✔（法兰在圆心正上方 0.165 m，工具竖直朝下，与抓取姿态要求一致）。

## 实现说明

- `se3.py` 不依赖 scipy；numpy 只作数组容器与逐元素算术。旋转矩阵 → 四元数用
  Shepperd 法（取四个分量中最大者作分母，数值最稳）；万向锁（cos(ry) ≈ 0）时按
  约定取 rz = 0，由 R01/R11（或四元数对应项）解出 rx。
- RPY 主值分支约定 ry ∈ [−90°, 90°]；该分支内 rpy ⇄ R ⇄ quat 严格互逆（单元测试
  覆盖随机样本、单轴 90°/180°、万向锁与 scipy 对照，共 13 项全部通过）。
- 所有验证阈值均为考题要求的 1e−9；实际残差为 0 ~ 1e−15 量级（双精度舍入水平）。
